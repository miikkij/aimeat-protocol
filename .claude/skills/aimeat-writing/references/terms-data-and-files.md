# Language context: files, data products and incoming data

The decided words for file stores and buckets, data packages and data products, outside parties and shares, data spaces, the data library, incoming webhooks and data contracts, contexts and tags.

Read `language-rules.md` first: it says what the decided words bind you to, which words are
forbidden, and how a row is added or changed. `language-context.md` lists the other area files.

| The thing | In one sentence | en | fi | es |
|---|---|---|---|---|
| where stored files keep their bytes, for the whole server | the server's own database, one S3 bucket or one Azure Blob container, chosen by the operator on the Config page; the admin page that shows it, tests it and moves older files has this name. An operator word: a person's page never needs it | file storage (the place: the server's storage) | tiedostojen tallennus (paikka: palvelimen tallennustila) | almacenamiento de archivos (el lugar: almacenamiento del servidor) |
| a person's own bucket or container for their files | an S3 bucket or Azure Blob container the person connects with their own keys; the node tests it before it saves anything, their new files go there and do not use the service's space; the operator's rule says whether they may, or whether an operator approves each person first. The verbs are connect and disconnect, never *irrottaa*, which is for an app's tie | your own storage; connect, disconnect | oma tallennustila; yhdistää, katkaista yhteys | tu propio almacenamiento; conectar, desconectar |
| the named place inside the cloud service | S3's *bucket* stays English in all three languages, as the services' own consoles keep it; Azure's *container* is *säilö*, Microsoft's Finnish word, and *contenedor* | bucket / container | bucket / säilö | bucket / contenedor |
| the folder inside a bucket or container | where one server's or one person's files go; *prefix* in the code and the API, never on screen | folder | kansio | carpeta |
| one named place that keeps files | a bucket or container under a name the person or the operator gave it; a person may have several, and the server may have several beside the one the Config page sets. Countable in all three languages; the uncountable *storage* / *tallennustila* / *almacenamiento* of the rows above stays for the idea of keeping files in one's own place | store, with its name: your store "archive" | tallennustila, nimineen: oma tallennustilasi "arkisto" | almacenamiento, con su nombre: tu almacenamiento "respaldo" |
| a store of the server, as a person reads it | one of the server's named stores that the operators opened for everyone; on the admin page it is just the store "x" | the service's store "x" | palvelun tallennustila "x" | el almacenamiento "x" del servicio |
| the store a new file goes to when its writer chooses none | one per person among their own stores, and one among the server's stores; with none, the Config page's setting decides. *Oletus* follows *oletusarvo* above, *predeterminado* follows *valor predeterminado* | default; make default, stop being the default | oletus; tee oletukseksi, poista oletus | predeterminado; hacer predeterminado, quitar como predeterminado |
| a server store every person may choose for a file | the operator's switch on a named store; an operator may always choose any store | open to everyone; open to everyone / only for operators (the actions) | valittavissa kaikille; avaa kaikille / vain operaattoreille | abierto a todos; abrir a todos / solo para operadores |
| a browser sending a file to a store without the service in between | the browser PUTs to the bucket or container with a link the service signed for one file; the alternative is the file going through the service. The setting that allows it is the store's *CORS rule*, kept as the abbreviation in all three languages because the consoles show it so; the field names in the rule (Allowed origins, Allowed methods) stay in English as the consoles show them | straight from the browser; the CORS rule | suoraan selaimesta; CORS-sääntö | directamente desde el navegador; la regla CORS |
| the choice on the upload form | the select that names the store a file's bytes go to; its first answer is where new files go now, and then nothing is sent | where to keep it | mihin tallennetaan | dónde guardarlo |
| one published table set | the CSV tables, their schema and who made them, at a permanent address per version; a person and a program read it | data package | datapaketti | paquete de datos |
| a table built from the person's own material on a schedule, with who may read it | a data package plus its promise: the sources, the columns, how often it updates and who may use it; the Offers page lists them and a six-step wizard makes one (plan doc-mvwxcas3dom3, section 4) | data product | datatuote | producto de datos |
| where a data product's rows come from | a workspace's records, an app's data, a memory record, a file, an extension's result or another data product; a product can have several, and the wizard's first step is named after them. Spanish takes *fuente*, as the Power Query feed is *fuente OData*; *origen* stays for the Origin tab and the source field | source | lähde | fuente |
| whether a data product keeps the promise it made | the last successful update against the schedule it promised: within it, one update late, three missed, or no schedule promised. A state never says *tuore* or *fresco*, which read as food. The list's column heading is *Ajantasaisuus* (Jouni, 2026-11-03), and Spanish *Actualidad* | up to date / late / out of date / no schedule | ajan tasalla / myöhässä / vanhentunut / Ei ajastusta | al día / con retraso / desactualizado / Sin programación |
| a data product that updates when its source changes | no clock: a change of the workspace's records, an app's data, a memory record, a file or another data product runs it after ten quiet seconds and at most every five minutes; an extension source cannot, the server sees no change there | when the source changes | kun lähde muuttuu | cuando cambia la fuente |
| the description the person's own AI writes for a data product | made from the name, the sources and the columns; a draft the person changes, never published by itself | description draft | kuvauksen luonnos | borrador de la descripción |
| a person or a program with no account here that the owner shares data with by name | made by the owner, holds a key (*avain*, *clave*), reads only what was shared with it; never an account of the node (services/parties/). A short-lived credential made from the key, and a data space's shared credential, stay *token* | outside party (party) | ulkopuolinen osapuoli (osapuoli) | parte externa (parte) |
| the owner's grant of one data product to one outside party | a consent with a purpose and an end date; ending it refuses the next read, copies already taken stay. The verb for ending it is *peru* in Finnish; the recipient's own act is *lopettaa* (*End the share*). Spanish says *acceso* in a short label ("2 accesos") | named share; share by name | nimetty jako; jaa nimetylle | acceso compartido nominativo (in a sentence: acceso nominativo); compartir de forma nominativa |
| the file a program reads a share with | a Delta Sharing style profile: the OData address, the party's name, the key once, the end date, the CSV addresses and the tables | connection file | yhteystiedosto | archivo de conexión |
| a link mailed to a person with no account, which opens one share once | the recipient accepts the terms on its page and takes a key made at that moment; it works once, until the share ends or 14 days. Spanish never calls it *enlace de acceso*, which is the sign-in link above | link (one-time link) | linkki (kertakäyttöinen linkki) | enlace (enlace de un solo uso) |
| a share to a person with an AIMEAT account on another server | by their account name@server, no party and no key: they sign in here from their own server as a visitor and read it | from another AIMEAT (their AIMEAT account) | Toisesta AIMEATista (hänen AIMEAT-tilinsä) | desde otro AIMEAT (su cuenta de AIMEAT) |
| the public page of one public data package | what DCAT, schema.org, the dataset sitemap and IndexNow name; no sign-in | the public dataset page; "Data catalogue" in its crumb | aineiston julkinen sivu; murupolussa "Datakatalogi" | página pública del conjunto de datos; "Catálogo de datos" en la ruta |
| the licence a data package names | the terms a reader keeps to (CC BY 4.0, CC0, or only a contract with the maker), shown as its name linking to the deed and one sentence of what the reader may and must do. Creative Commons' own titles: *Nimeä 4.0 Kansainvälinen*, *Atribución 4.0 Internacional*, *CC0 1.0 Yleismaailmallinen*. It is never called *käyttöehdot* where a licence is meant (Jouni, 2026-11-02) | licence | lisenssi | licencia |
| who a reader credits when they use a data package | the maker's own words under the licence (CC BY asks for it); the heading is an instruction, the field label says what to write. Finnish follows the CC deed's *mainitse lähde*, Spanish its *citar la fuente*; *nimeäminen* is not used | attribution; "Credit the source like this" (heading), "How to credit the source" (field) | lähteen mainitseminen; "Mainitse lähde näin", "Miten lähde mainitaan" | atribución; "Cita la fuente así", "Cómo citar la fuente" |
| the language a data product's own words are written in | the title, description and attribution per language; the page's own language edits the base words every other reader falls back to | the language of these words; the base words | tekstien kieli; perustekstit | el idioma de estos textos; los textos de base |
| the Config group of how data leaves the node | data intermediation, app registration without an account, the Dataspace Protocol and the longest share | Data out | Data ulos | Salida de datos |
| an EU data space | a network of organisations whose connectors (*liitin*, *conector*) speak the Dataspace Protocol; Finnish keeps the hyphen between the two a's, as Sitra writes it | data space | data-avaruus | espacio de datos |
| an organisation in a data space | identified by its DID; it reads this server's catalogue, makes a contract and pulls the data | participant | osallistuja | participante |
| the profile page that lists every data package the person lets others use | the data products, the shares to people and who reads, with the filters All, Public, Named shares, For sale and Data space; the owner's AI reads the same list | Data you share | Jakamasi data | Datos que compartes |
| how far one reader reaches in the library | the library's tiles: what anyone may read; what other accounts shared with this account, its organisms or everyone signed in here; the reader's own; what an outside party's key opens (boards Main, Kirjasto-kirjautunut, Kirjasto-avaimella) | Public; Shared with you; Yours; With your key | Julkiset; Jaettu sinulle; Omasi; Avaimellasi | Públicos; Compartido contigo; Tuyos; Con tu clave |
| the owner refuses an outside party's reads or sign-in without deleting it | its role, keys and data stay; "let in again" undoes it. Finnish uses the same verbs for a registered person and for an outside party in the Data Wallet; English and Spanish say Resume / *Reanudar* there | stop; let in again | pysäyttää; päästää takaisin | detener; dejar entrar de nuevo |
| an address and an API key through which an outside program writes into one place of the owner's data | the page Incoming webhooks (Automation), tab `receivers`; one memory key, the keys under one prefix, or one row space, chosen when it is made; an agent may propose one, and the owner approves it in person. The owner pauses and resumes it (*keskeyttää / jatkaa*, *pausar / reanudar*); the operator stops and starts it (*pysäyttää / käynnistää*, *detener / iniciar*), which the owner cannot undo. Every machine name keeps the old word: the routes `/v1/receivers` and `/v1/receive`, the tool `aimeat_receiver`, the scopes `receivers:manage` and `receivers:read`; a text that names one says the term beside it once. After the first mention a sentence may say *webhook* alone. Where the webhooks the node sends must be told apart, those are *outgoing* (*lähtevä*, *saliente*) | incoming webhook; the page: Incoming webhooks | saapuva webhook (*saapuvan webhookin*, *saapuvia webhookeja*); the page: Saapuvat webhookit (*Saapuvat webhookit -sivulla*) | webhook entrante (masculine); the page: Webhooks entrantes (*la página Webhooks entrantes*) |
| the credential an incoming webhook's program sends | `aimeat_rcv_…`, shown once when the incoming webhook is made, approved or its API key is changed; listed with what acts in the owner's name on the Access page. Always *API key* on these pages, because the same page also names memory keys (*muistiavain*, *clave de memoria*). Changing it is *Vaihda API-avain* / *Cambiar la clave de API*; the old API key keeps working for 15 minutes | API key; change API key | API-avain; vaihda API-avain | clave de API; cambiar la clave de API |
| the described shape and rules of the data an outside program sends, checked on every write | a CSM (`/v1/csm`, `aimeat_csm`), drafted from one example message; its name starts with the owner's account; it has versions and a choice of who may read it. An incoming webhook with one refuses a message that does not match | data description (CSM) | tietokuvaus (CSM) | descripción de datos (CSM) |
| one call a program made to an incoming webhook, stored or refused | the webhook's log keeps the newest 200, never a message's content; the filter says *Hylätyt* / *Rechazadas* | delivery | toimitus | entrega |
| a test call that is checked like a real one and stores nothing | `?dry_run=true`; the incoming webhook's dialog sends one with the API key just shown. Spanish says what it does rather than a calque of *dry run* | test without storing; dry run | koeajo; koeajo ilman tallennusta | prueba sin guardar |
| something larger a person keeps working on with their AI | a project, an ongoing conversation with someone, a trip, a story world; one memory record under `context.<slug>` that their AI makes and keeps up to date in chat, and that every AI they connected reads. The Contexts page (Information, tab `contexts`) lists them; *update* (*päivittää*, *actualizar*) is what the AI does to one, never *shape* on screen. Its parts: core (*ydin*, *núcleo*), concepts (*käsitteet*, *conceptos*), references (*viittaukset*, *referencias*), kept views (*ylläpidetyt näkymät*, *vistas que se mantienen*); archive as for conversations above | context | konteksti | contexto |
| a short word on a memory record to find and group it by | the record's own `tags`, set by the person's AI; the Contexts page shows them and lists by one. Never *tunniste*, which is a machine identifier (see the Purview row) | tag | tagi | etiqueta |
