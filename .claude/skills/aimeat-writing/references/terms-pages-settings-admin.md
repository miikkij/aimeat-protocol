# Language context: pages, settings and the admin side

The decided words for the home and the block that starts a page, settings and their question marks, the look of this AIMEAT's own pages (themes, styles, fonts, components), form checks, the operator's settings and data key, and one row per Settings or admin page.

Read `language-rules.md` first: it says what the decided words bind you to, which words are
forbidden, and how a row is added or changed. `language-context.md` lists the other area files.
