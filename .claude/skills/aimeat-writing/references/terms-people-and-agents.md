# Language context: people, systems, memory and agents

The decided words for the person and their own AIMEAT, other AIMEATs and the server underneath, federation, stored memory and knowledge, agents and the AI a person talks to, permissions, and signing in.

Read `language-rules.md` first: it says what the decided words bind you to, which words are
forbidden, and how a row is added or changed. `language-context.md` lists the other area files.

| The thing | In one sentence | en | fi | es |
|---|---|---|---|---|
| the person's own system | the running AIMEAT their account lives in | your own AIMEAT | oma AIMEAT | tu propio AIMEAT |
| someone else's system | another AIMEAT they can sign into and whose memory they browse | environment / remote environment | ympäristö / etäympäristö | entorno / entorno remoto |
| another AIMEAT joined to this one | an installation this one federates with: its people may sign in here and data crosses between the two; an operator word, on the federation and security admin pages | peer | vertainen | par |
| what a peer credits here | a signed message from a peer that adds morsels to a person on this AIMEAT; an operator word, on the federation page and its notices | settlement | selvitys | liquidación |
| the most morsels added from nothing in a day | the node's ceiling on morsels that no balance here paid (mints, pacing-pack sales and peers' settlements count against it); a peer can have a ceiling of its own; "none" is no limit | daily ceiling (per peer: settlements a day) | päiväraja (vertaiselle: selvitykset päivässä) | límite diario (por par: liquidaciones al día) |
| the machine | the host, when the sentence is really about the machine: what holds a credential, what has an address, what is reachable | server | palvelin | servidor |
| whoever pays for the shared AI key | the operator of this installation, on an operator surface | this server / the server's key | palvelin / palvelimen avain | este servidor / la clave del servidor |
| stored knowledge | what the person and their agents wrote here | memory | muisti | memoria |
| one stored thing | a single record under one key | entry | merkintä | entrada |
| refined knowledge kept to reuse | research or other material the person brought, packed by their AI into entries that each carry their sources; the page that holds it is Knowledge / Tietopankki / Conocimiento | knowledge base | tietopankki | base de conocimiento |
| one bundle of that knowledge | a named set of knowledge entries with their sources and the links between them, made by the person's AI; it can be listed in the public library, copied into another person's knowledge base, or shared with a shared place | knowledge package | tietopaketti | paquete de conocimiento |
| the AI acting for them | scoped, named, revocable, acts in their name | agent | agentti | agente |
| what sort of agent it is, as a column | the column of the Agents list that holds an agent's mode (task runner, workstation…), the platform it runs on and whether it is federated; a heading for those tags, never a setting (Jouni, 2026-10-19) | Kind | Tyyppi | Tipo |
| an agent's own picture | the emoji or drawing (an SVG, which may move) the agent chose for itself, shown wherever the person sees it; public, like its description. The node's own word in all three languages; never *profiilikuva* for an agent, which is a person's (Jouni, 2026-10-19) | avatar | avatar | avatar |
| where an agent runs | the computer that runs a person's agents: the program `aimeat connect serve` is on it, the person gives it a name, and an agent is ordered to one of them. Say the kind when it matters: laptop, server, a computer in the cloud, or an AIMEAT instance from the store (fi and es say *oma AIMEAT* / *tu propio AIMEAT* for that one). Never *machine*, *kone* alone or *máquina*, and never *connector* outside an operator page or the API (Jouni, 2026-10-11) | computer | tietokone | computadora |
| a program a computer may start | an agent's runner (started for each task) or wake command (started on new work), which the computer starts only when the person allowed it, at the computer or on the Your computers page. Its states: allowed, waits for approval, not allowed (2026-10-31) | program it may start; allowed / waits for your approval / not allowed | ohjelma, jonka se saa käynnistää; sallittu / odottaa hyväksyntääsi / ei sallittu | programa que puede iniciar; permitido / espera tu aprobación / no permitido |
| the AI a person talks to | their own Claude, ChatGPT or other chat AI, connected here or not; Finnish inflects *tekoäly* as a word and never writes *AI:lle*, *AI:sta* or *AI:n* (2026-10-03, 61 strings rewritten) | your AI | tekoälysi | tu IA |
| a ready text to copy into an AI | the words the page composes for the person's own AI; the person reads it before the AI runs it, and the work is in its wording. Finnish never says *prompti* | prompt | kehote | prompt |
| whoever runs this AIMEAT, on a person's page | the company or person answerable for the service, named from the privacy settings; not the machine | runs this service / the operator | ylläpitää palvelua / palvelun ylläpitäjä | lo gestiona / quien gestiona este servicio |
| a task that waits for the owner before it starts | the agent has proposed its plan and the work begins only when the owner presses Start or tells their AI to start it; the opposite is a task that starts on its own | waits for your OK / starts on its own | odottaa lupaasi / aloittaa työn itse | espera tu permiso / empieza por sí solo |
| an agent the owner stopped | the owner's own decision, taken back with one press: the agent finishes the work it has and starts nothing new; tasks and messages given to it wait, its scheduled runs are skipped, and its key and permissions stay. It is not the same as a computer that is not connected, and not the same as removing the agent. The verbs are stop and start, also when the person says "pause"; the switch on the agent's card is named by what on means ("Takes new work") | stopped / stop, start (switch: Takes new work) | pysäytetty / pysäytä, käynnistä (kytkin: Ottaa uutta työtä) | detenido / detener, iniciar (interruptor: Recibe trabajo nuevo) |
| the statement that an app shows an agent's work | one row of the app's data map that names the agent; the agent's page lists the app and the app's page lists the agent. It is information and gives no permission. The verbs are tie and untie. Finnish never says *side* or *sidos* for it, and Spanish never *vínculo* or *vincular*, which is the word for binding an AI role | tie / tie, untie | liitos / liittää, irrottaa | asociación / asociar, quitar la asociación |
| that an app or an agent invites people | an app or an agent holding the permission organism:invite may invite people into the shared spaces its owner belongs to, and an invitation can create a new account: an email invitation the person accepts, or an invitation code an organism owner makes. It is allowed, and it is said: on the app's data map under "Who it invites", on the agent's page and card, and in the proposal the owner approves. The code that makes an account is an invitation code, Jouni's word *kutsukoodi*; Finnish never says *pääsykoodi* for it | invites people / invitation code | kutsuu ihmisiä / kutsukoodi | invita a personas / código de invitación |
| where an agent's finished work goes | the owner's one choice per agent: the agent's own memory, which only the owner reads, or one workspace, whose members then read each result the agent finishes; nothing is copied or moved | where its work goes | minne sen työ menee | adónde va su trabajo |
| what gives an agent work from a workspace | the owner's choice on the new-agent page under "When it works": one workspace and the record spaces in it; each record published there becomes one task for the agent. A row and a document page give it no work. It is a different choice from where its work goes, which wakes nobody. The verb is watch. Taking the agent off the workspace is retire, as on the Contracts tab (*poistaa käytöstä*, *retirar*); Finnish never says *irrottaa* for it, which is the word for untying an app | when something new arrives in a workspace / watch (a space) | kun työtilaan tulee jotain uutta / seurata (tilaa) | cuando llega algo nuevo a un espacio de trabajo / seguir (un espacio) |
| permission a person grants | revocable, per agent, per area | permission | oikeus | permiso |
| an agent adding permissions to another of the owner's agents | the owner allows it per agent, signed in themselves (agent:permissions-add); the agent then gives only permissions it holds itself, never to itself, and each addition is a line on the home feed and a notice in the bell; the opposite act is *take away* (*poistaa*, *quitar*) | give (permissions to another agent) | antaa (oikeuksia toiselle agentille) | dar (permisos a otro agente) |
| narrowing an agent that has all permissions | its "all permissions" is replaced with the permissions it used; only the owner does it, with one press on the agent's page or through their AI, and the page says what the narrowing takes away; the node never does it by itself (Jouni, 2026-10-28) | narrow (to the permissions it used) | rajata (käyttämiinsä oikeuksiin) | limitar (a los permisos que usó) |
| sign-in from elsewhere | another AIMEAT vouching that a sign-in is really them | federation | federaatio | federación |
| the account holder | the human who owns everything here | owner | omistaja | propietario |
| the service the person is on | the AIMEAT they are reading this screen on, which is a thing with a name | this service, or its name | tämä palvelu, tai sen nimi | este servicio, o su nombre |
| the list of public systems | where a public AIMEAT can be found by others | the federation directory | AIMEAT-palvelimien luettelo | el directorio de la federación |
| a machine credential | what a program presents to prove it may connect | token | token | token |
| a machine identifier | a name for a thing, never for a person | identifier / ID | tunniste | identificador / ID |
| a person's login name | the public half of a sign-in | username | käyttäjätunnus | nombre de usuario |
| the email domains a sign-in provider may vouch for | only an address in one of them joins an existing account with the same verified address, or becomes a new account's verified address; `*` is every domain | trusted domains | luotetut verkkotunnukset | dominios de confianza |
| the address the server answers on | this machine only (127.0.0.1), or every network that reaches the machine (0.0.0.0); a server open to the network gets the public safety defaults | listen address (this machine only, local network) | kuunteluosoite (vain tämä kone, lähiverkko) | dirección de escucha (solo esta máquina, red local) |
| a link in an email that signs a person in | works once and needs no password; asked for on the sign-in dialog (15 minutes), or sent with the welcome mail when an install set creates the account (7 days) | sign-in link | kirjautumislinkki | enlace de acceso |
| the window a person signs in or creates an account in | opened by the Sign in button and by apps; its headline and the line under it may be the operator's own words per language (Config, auth.sign_in_title_* and auth.sign_in_line_*) | sign-in dialog | kirjautumisikkuna | ventana de acceso |
