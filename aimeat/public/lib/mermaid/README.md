# Vendored Mermaid

`mermaid.min.js` is the single-file UMD build of Mermaid v11.15.0 (MIT), copied from
`node_modules/mermaid/dist/mermaid.min.js`. Served locally (no CDN), lazy-loaded by
`public/components/Mermaid.js`. To update: `pnpm add mermaid`, copy the dist file here,
then `pnpm remove mermaid`.
