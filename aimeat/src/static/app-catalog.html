❓ How this catalog works

Global vs Personal

Both are on THIS browser. Global apps are shared across every account signed in on this browser; Personal apps are private to your account. Personal needs you to be signed in.

Where your apps live

"Local Apps" live only in this browser (IndexedDB) — they don't follow you to another browser or device. Publish an app to put it on the server, and then you can manage it from anywhere. Keeping an app local-only is a valid choice; it just stays here.

The sections

Published = your apps on the server. Parked = your server apps hidden from the public catalogue but still usable by you. Community = other people's published apps. Local = apps only in this browser.

"Backup" means two different things

The 💾 menu (top bar) exports/imports your SERVER apps + extensions as a .zip. Settings → Export/Import JSON backs up this browser's LOCAL catalog. They are separate.

Run it against your own node

Set Settings → Server URL to point the catalog at any AIMEAT node (e.g. your own localhost or a federated node). This page is meant to be usable standalone against the node you choose.

🕑 App Versions

Every publish is kept. Restore re-publishes an older version as the new latest; Fork copies it into a new app. Older versions are never lost.

⥂ Fork lineage

Every app that was forked from this one (and where this one came from), with each fork's current status. The chain survives a fork being parked or deleted.

🛡️ Copy protection

Optional, per-app. These raise the cost of casual copying and make leaks traceable — they cannot stop someone who can view the app from copying its HTML. To truly protect logic or data, put it in a server-side extension.
