# The E2E suites whose expected answers depend on the release the node runs. The nightly sweep
# (.github/workflows/e2e-full.yml, job release-4-0-0) runs exactly these on SQLite with
# AIMEAT_TEST_SOFTWARE_VERSION=4.0.0, so the 4.0.0 half of every version-aware assertion is run
# every night and not only by hand. Their 3.x half runs in the ordinary sweep.
#
# A suite belongs here when it branches on the release or names a removal: it calls removedOn() or
# imports helpers/node-release or helpers/owner-key-sign-in, reads AIMEAT_TEST_SOFTWARE_VERSION,
# calls versionAtLeast(), or names a *_REMOVED_IN constant. test/unit/version-aware-suites.test.ts
# refuses a suite that does any of these and is not listed, and a listed name that is no suite.
#
# e2e-node-update asserts that the node reports AIMEAT_TEST_SOFTWARE_VERSION on GET /v1/build, so a
# run that did not start the node as 4.0.0 fails there and is not green by accident.
#
# Run the same list locally (from aimeat/, on your own claimed port):
#   AIMEAT_TEST_SOFTWARE_VERSION=4.0.0 node --env-file=.env.test.sqlite --import tsx test/run-e2e-ci.ts --tests-file=test/version-aware-suites.txt
