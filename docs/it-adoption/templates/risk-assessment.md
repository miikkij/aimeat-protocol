# Template: risk assessment

> Checked against AIMEAT node 4.2.0 (commit 959664aab) on 2026-11-02. Maintained with the code: see the README for how.

## How to use

Each row is one risk, grouped under confidentiality, integrity, availability and AI. The threat and the AIMEAT controls are pre-filled from the [threat model](../../security/threat-model.md), [08 Threat model](../08-threat-model.md) and the code each control is in; "What stays with you" names the part no software setting covers. You score likelihood (L) and impact (I) on your own scale, for example 1 (rare, minor) to 5 (almost certain, severe), name an owner, and choose a treatment: accept, reduce (say how), transfer or avoid. A score is about your installation, so AIMEAT gives none. Add rows for risks of your own at the end; strike a row only with a reason written in the treatment cell.
