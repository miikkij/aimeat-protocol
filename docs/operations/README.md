# Operating a node

Guides for the person who runs an AIMEAT node: putting it on a public address, keeping it safe to
restore, moving it to a new version, and connecting it to other nodes. Day-to-day operation is done
from the admin page and by an operator's AI with the `aimeat_admin_*` tools; the built-in skill
`aimeat-node-operations` teaches an AI those.
