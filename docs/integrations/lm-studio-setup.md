# LM Studio connection

Use the [client report](../aiplatforms/lmstudio.md) for the dated LM Studio setup
and the [connection guide](../c-platform-notes.md) to choose the connection
available in your installed client.

For a local node, follow the [personal node guide](../personal-node-setup-guide.md).
For an authenticated agent, follow
[agent onboarding](../building-an-aimeat-compatible-agent.md).
Discover tools from the connected node rather than relying on an old tool count.

Running inference locally does not by itself prevent network access. Node
federation, remote tools, extensions and provider configuration determine where
requests go. Set those according to the intended environment.
