# Historical documentation

These files preserve earlier designs, implementation plans, audit results and
manual test plans. Their commands, counts, status labels and provider references
describe the time they were written. They are not current operating instructions.

The 2026-09-16 cleanup moved the old package-local `analysis/`, `plans/`,
`superpowers/` and `e2etests/` trees under `node/`. The old OpenAPI sync plan is
here too. Each file records its former path. Git retains the original history.

Use [the current documentation index](../README.md) and [file catalog](../catalog.md).
Executable tests live in `aimeat/test/`; current work and unresolved requests live
in Lifecycle Central. Read the applicable source and current board before acting
on an unchecked task in an archived plan.

The archive is retained for historical reference. Do not update an old result to
look current. Put current guidance in its maintained guide and link to history only
when the earlier decision is needed to understand it.
