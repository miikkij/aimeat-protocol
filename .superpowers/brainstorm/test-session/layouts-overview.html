aimeat-ui-layout — Mitä layouteja tarjotaan?

Valitse kaikki jotka pitäisi sisällyttää. Klikkaa haluamasi.

1

Main-Detail

Lista vasemmalla, valitun kohteen tiedot oikealla. Klassinen master-detail pattern.

2

Portrait (Single Column)

Yksi keskitetty kolumni — sopii profiileihin, artikkeleihin, lomakkeisiin. Max-width rajattu.

3

Landscape (Wide)

Leveä sisältö ilman max-width-rajoitusta — dashboardit, taulukot, monitorit.

4

Fibonacci / Golden Ratio

Sisältö jaettu kultaisen leikkauksen suhteessa (61.8% / 38.2%). Esteettinen, tasapainoinen.

5

Holy Grail

Header + sidebar + main + sidebar + footer. Klassinen web app layout.

6

Split (50/50)

Kaksi samankokoista paneelia vierekkäin — vertailu, ennen/jälkeen, dual view.

7

Stacked Sections

Pystysuuntaiset osiot — landing page, one-pager, scrolling story.

8

Dashboard Grid

Widgettejä ruudukossa — stat-kortit, graafit, listat. Responsiivinen auto-fit.
