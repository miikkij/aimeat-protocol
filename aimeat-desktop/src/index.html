No local AI yet? Set up Ollama (free)

          

            Ollama runs open models locally on your machine and serves them at http://localhost:11434.
          

          
    
            
  1. Download & install Ollama
              
    2. 
            
  2. Pull a model — open a terminal (PowerShell) and run:
              
    
                ollama pull qwen2.5:7b
                
              
    
            
    3. 
            
  3. Come back and click Scan Again above — it'll show up as Available.
    4.

    4. 
        
  4. Restart the agent.
    5. 
      

      
This costs money — you control how much. The free local agents stay free.
